# Security Policy

Please report security vulnerabilities in {{name}} privately. Do not open a public GitHub issue for them.

## Reporting a Vulnerability

Email [support@lightspeedwp.agency](mailto:support@lightspeedwp.agency) with `[SECURITY]` at the start of the subject line. Include:

- A description of the vulnerability and its impact (Low, Medium, High or Critical).
- Steps to reproduce it.
- The affected versions.
- A suggested fix, if you have one.
- How we can reach you for follow-up.

## Response Times

| Severity     | Initial response | Fix target |
| ------------ | ---------------- | ---------- |
| **Critical** | 4 hours          | 48 hours   |
| **High**     | 1 business day   | 7 days     |
| **Medium**   | 3 business days  | 14 days    |
| **Low**      | 5 business days  | 30 days    |

We acknowledge each report, confirm its severity, release a fix and credit the reporter in the release notes, unless they prefer to stay anonymous.

## Supported Versions

Security fixes are released for the latest version only.

## Standards

The plugin follows the [WordPress security guidelines](https://developer.wordpress.org/apis/security/) and the [WordPress Coding Standards](https://developer.wordpress.org/coding-standards/wordpress-coding-standards/): it escapes output, sanitises input and checks nonces and capabilities.
