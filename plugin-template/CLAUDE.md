# Claude Code: {{name}}

@AGENTS.md

- Skills in `.claude/skills/` link to the shared skills in `.agents/skills/`; the `speckit-*` skills are generated by Spec Kit.
- The WordPress skills (`wp-plugin-development`, `wp-block-development`, `wp-rest-api`, `wp-plugin-directory-guidelines`, `wp-phpstan` and others) are unmodified copies of WordPress/agent-skills; see `.agents/skills/VENDORED.md`. Use them for plugin architecture, blocks, REST endpoints, Plugin Check and static analysis.
- Agents in `.claude/agents/` load their instructions from `.agents/roles/`.
- `.claude/settings.json` runs `.claude/hooks/check-branch.mjs` before Bash and file edits. It refuses commits, pushes and edits on `main`, `develop`, `release/*` or a branch whose name `bin/check-branch-name.js` rejects, and refuses to create such a branch. Put machine-specific settings in `.claude/settings.local.json`, which Git ignores.
- `.claude/settings.json` enables the `ls-claude-agents-router` plugin from the `lightspeedwp` marketplace, which routes the organisation agents in `lightspeedwp/.github` into Claude Code. Claude Code offers to install it when you trust this folder. It needs `~/.github` cloned (on `develop`) and Git access to the private repository (`gh auth login`, then `gh auth setup-git`).
